# Особистий кабінет студента

Інформаційна система «Особистий кабінет студента».

**Тип системи:** Web  
**Автор:** Yaroslav Zahorovskiy  
**Варіант:** 2 — заклад вищої освіти / державна установа

**Короткий опис:** Веб-система для замовлення студентами довідок і взаємодії з деканатом.

## Призначення

Система призначена для надання студентам централізованого доступу до актуального розкладу занять, оголошень деканату та можливості замовлення довідок онлайн.

## Документація

Документація проєкту та матеріали попередніх практичних робіт зберігаються в каталозі `docs/`.

- C# / ASP.NET Core — запланований стек серверної частини.
- Git і GitHub — контроль версій та зберігання репозиторію.
- GitHub Projects — організація задач проєкту.
- Web — тип програмної системи.
